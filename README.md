# Cederis Retail System

Cederis Retail System is an in-development open source Point-Of-Sale system created by [TheCamoGamer](https://github.com/TheCamoGamer). This fork is a port to modern Linux systems.

## Branching Scheme

- `main` - Stable major versions of CRS.
- `Beta` - Active development of CRS.

## Why Fork?

Simply because I can and I want a native Linux port of the project.
